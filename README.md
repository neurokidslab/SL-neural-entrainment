# Codes to compute neural entrainment 

> Authors: Ana Flo (anaflom@gmail.com)

This repository provides the codes to compute neural entrainment during the statistical learning task as describe in the following paper: https://doi.org/10.7554/eLife.101802.1 
All routines are implemented in MATLAB.

#### Requirements
* <a href="https://mathworks.com/" target_="blank">MATLAB</a>
* <a href="https://sccn.ucsd.edu/eeglab/" target_="blank">EEGLAB toolbox</a> (recommend >=14.0)
